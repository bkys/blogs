2. LDO 关键参数说明
静态电流（Iq）：LDO 正常稳压、负载极轻时内部控制电路的耗电，是衡量自身功耗的核心指标，数值越低越适合电池供电。
压差：输入电压与输出电压的最小差值，压差越低，越适合输入输出电压接近的场景。

2. 选型搭配建议
低功耗 LDO（如 XC8203）优先搭配 CR2032/CR2025，3V 电压匹配度高，低自放电适合长期待机。
与 LDO 搭配时，输入电压需高于 LDO 输出电压 + 压差。

3. 低功耗优化关键措施
电源选型：优先使用 XC8203（0.6μA 静态电流）替代高功耗 LDO，降低自身损耗。
时钟优化：运行时选用内部低速时钟（如 8MHz HSI），低功耗模式下关闭所有外部晶振。
外设与 GPIO：关闭未使用外设，GPIO 配置为浮空输入，禁用上拉 / 下拉电阻。
唤醒策略：采用外部中断唤醒，减少单片机持续上电时间。
